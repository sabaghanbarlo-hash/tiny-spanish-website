# Tiny Spanish 🇪🇸

Spanish for English speakers with **Emma** and **Mateo**. A fast, accessible, no-dependency website:
lessons, courses (A1–B2), searchable vocabulary, grammar, quizzes, and local progress tracking.

- **No paid APIs, no accounts, no framework.** Static HTML generated by `build.mjs`, plus small ES-module scripts.
- **Progress is stored in the browser** (`localStorage`): completed lessons, quiz scores, learning streak, XP, learned words. Export/import a backup from the *My Progress* page.
- **Audio** uses the browser's free text-to-speech (prefers Latin American Spanish voices). Real recordings can be added per sentence (see below).

## Run it

```bash
npm run dev      # builds and serves http://localhost:4173
npm run build    # writes ./dist
npm test         # builds, then runs unit + link/quiz integrity tests
```

Requires Node 18+. Environment variables for production builds:

| Variable | Purpose | Example |
|---|---|---|
| `SITE_URL` | canonical URLs, sitemap, social tags | `https://tiny-spanish.example.com` |
| `BASE_PATH` | only when hosted in a sub-folder (GitHub Pages project site) | `/tiny-spanish-website` |

## Add content (no code changes needed)

| To add… | Edit | Notes |
|---|---|---|
| a lesson | `data/lessons.js` | add an object, then list its `slug` in a unit in `data/courses.js` |
| a video | the lesson's `video` field | `{ type: 'youtube', id: '…' }` or `{ type: 'file', src: '/media/x.mp4' }` (put files in `public/media/`) |
| audio | a sentence's `audio` field | e.g. `audio: '/media/hola-1.mp3'` (the Listen button plays the file; if it is missing or fails it falls back to text-to-speech) |
| vocabulary | `data/vocabulary.js` | new words or whole topics; quizzes for each topic are generated automatically |
| grammar | `data/grammar.js` | optional `table`, examples and tip |
| a quiz | `data/quizzes.js` | hand-written; lesson and vocabulary quizzes are auto-generated from the data |
| A2/B1/B2 | `data/courses.js` | write lessons with `course: 'a2'`, fill `units[].lessons`, set `status: 'open'` |

Everything (pages, sitemap, JSON for the quizzes and progress pages) is regenerated on build.

## Structure

```
data/      lessons, vocabulary, grammar, courses, hand-written quizzes
lib/       layout (head/header/footer), page templates, character SVGs, quiz generator
src/css/   one stylesheet with design tokens at the top of the file
src/js/    store.js (progress), ui.js (nav, speech, toasts), pages/* (one small module per page)
public/    static files copied as-is (og image, media)
tests/     node:test suites
```

## Characters

Emma (blonde ponytail, turquoise hoodie) and Mateo (brown hair, orange jacket) are inline SVG in
`lib/characters.mjs`, so they stay crisp and consistent everywhere. To use your official artwork instead,
change `character()` to return an `<img>` pointing at files in `public/assets/characters/`.

## Content status

Lessons are **AI-drafted placeholder content** and are marked as drafts until a native speaker reviews them
(`reviewed: false` in `data/lessons.js`). Lesson 12 (allergies / emergencies) is flagged for extra review.
Spanish is written in a neutral Latin American style; regional variants are noted in tips.

## Accessibility and SEO

Skip link, semantic landmarks, keyboard-operable quizzes (keys 1–4), visible focus, `aria-live` feedback,
reduced-motion support, per-page titles/descriptions/canonical/Open Graph, JSON-LD (WebSite, Course,
LearningResource), `sitemap.xml` and `robots.txt`.

## Deploy

Cloudflare: `wrangler.jsonc` is included (static assets from `dist/`). GitHub Pages also works with `BASE_PATH` set.

## Before launch

- Add `public/assets/og.png` (1200×630 share image). The Open Graph tags point to it, but it is not committed yet.
- Have a native speaker review the lessons (see *Content status*).

## Optional home-page content
- **Testimonials:** add real reviews to `data/testimonials.js` (`{ name, quote, stars }`). The carousel stays hidden while the list is empty.
- **Social icons:** set `SOCIAL_INSTAGRAM`, `SOCIAL_YOUTUBE`, `SOCIAL_TIKTOK`, `SOCIAL_PINTEREST` (https URLs) at build time; icons appear in the footer only when set.
